Cloud Platform

Complete private cloud infrastructure software that transforms your hardware into a self-service cloud platform. Deliver AWS-like capabilities with complete data sovereignty and local control.

Key Features

  • Multi-tenancy with complete resource isolation
  • Automated network orchestration (VPC, VRouter, Load Balancer)
  • Image management and template library
  • Resource metering, billing, and chargeback
  • Role-based access control (RBAC)
  • RESTful API for automation and integration

Container Orchestration

ZStack ZAKU

MetaVirt Kubernetes Unit

Enterprise Kubernetes platform fully integrated with ZStack Cloud. Deploy, manage, and scale containerized applications with the same operational model as your virtual machines.

Platform Features

  • Upstream Kubernetes with no vendor modifications
  • Integrated with ZStack Cloud networking (VPC, security groups)
  • Persistent volume integration with ZStack storage
  • Horizontal pod autoscaling (HPA)
  • Cluster autoscaling for node provisioning
  • Built-in monitoring and logging stack
  • Helm chart marketplace integration
